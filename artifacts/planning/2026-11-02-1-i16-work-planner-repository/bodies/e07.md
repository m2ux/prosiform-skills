## Overview

Work Planner is used through prosiform. Its entry point tells the reader to select a mode, run `pf` on it and follow its bundle, every mode compiles within the default output budget with no warning and against stubs of its artifacts and protocols, and each mode's bundle size is compared against a fixed baseline revision. Once the skill's files conform, the shared skill-file check gains its prosiform findings, so a later change that breaks a prosiform rule in any skill it runs over draws a finding.

## Problem

- **No mode is an entry.**
  No Work Planner document declares prosiform, so no mode compiles on its own, and compiling [SKILL.md](https://github.com/m2ux/workflow-server/blob/785a5ee8c715b802498aa41712e0489425a22cfa/skills/work-planner/SKILL.md#L19-L67) yields a 405673-byte bundle carrying every mode.
- **A mode is compiled only with everything it links.**
  A mode's own prose cannot be compiled apart from its artifacts and protocols, so a fault in one surfaces in every mode that reaches it.
- **Five modes overflow the default budget.**
  At [785a5ee8c](https://github.com/m2ux/workflow-server/tree/785a5ee8c715b802498aa41712e0489425a22cfa/skills/work-planner): Deliver 353717 bytes, Plan 328950, Advance 314874, Standup 273929 and Sync 264276, against 262144.
- **Nothing judges a unit's grain.**
  Whether a protocol, an artifact, or a procedure, operation, command or field within one is cut at the size its readers need is unmeasured, so a bundle carries content no step uses and a capability spreads across units, and a later change has no standard to be held to.
- **Nothing fixes what a change costs.**
  No record holds each mode's bundle size, so a change that grows a bundle is seen only when it crosses the budget.
- **The check reads resolution only.**
  The [shared skill-file check](https://github.com/m2ux/workflow-server/blob/785a5ee8c715b802498aa41712e0489425a22cfa/skills/scripts/check_skill_files.py#L1025-L1029) confirms that a link resolves; a whole-file link to a file with sections, a mode linking another mode whole, and a mode that overflows the budget all pass.

## Proposal

- **SKILL.md routes to a mode.**
  The entry point is read, not compiled. Its Modes list selects a mode, and its instruction is to run `pf` on the selected mode file and follow that bundle. Each mode is an entry; SKILL.md is none.
- **The grain is reviewed first.**
  Before any mode is fitted to the budget, each protocol and artifact, and each procedure, operation, command and field section it holds, is measured for its share of each mode's bundle, its reach across modes, its dead weight in bundles whose steps do not use it, and its cohesion against the modes, protocols and artifacts layering. Each unit takes a verdict of keep, split, merge or move; the planning record holds the report, and each confirmed change becomes a row ahead of the budget fit. The measures, thresholds and verdict rules become Work Planner's grain rubric, which Revise Mode applies to every new or changed protocol and artifact.
- **Each mode fits its bundle.**
  A mode still over the budget once its links carry prosiform's meaning first hands each step a sub-agent runs to a `⇉` link compiled into its own bundle, then is cut to its own procedure, moving a section only some steps use to a file of its own.
- **Each mode compiles against stubs.**
  Each mode declares a `test` preset whose `subst` pairs replace the artifacts and protocols it links with stubs, so the mode's own prose compiles and is checked apart from theirs. The skill's test suite compiles every mode with that preset.
- **One comparison fixes the cost.**
  Each mode's bundle at the settled revision is compared with its bundle at the baseline revision, compiled by one prosiform version on both.
- **The check enforces the prosiform rules over every skill it runs over.**
  It reports a whole-file link to a target with sections, a mode or protocol reaching a mode file without an operator, and a mode whose compilation crosses the budget or warns. A missing or mismatched `pf` is a finding, never a skip.
- **The findings land after the skill conforms.**
  The check gains them last, so no branch carries a finding against the skill's own files.
