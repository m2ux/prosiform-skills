**Component:** main:guidelines.md

## Overview

Prose in Work Planner and the shared guide names each check by linking its definition.

## Problem

The shared guidelines' Verified rule names the shared check as a code span, and Work Planner's Revise Mode names the check it runs by its path.

## Proposal

- Each sentence naming a check links its Checks entry, in the shared guide and in Work Planner.
- A command block running a check keeps its command; the sentence introducing it carries the link.

### File-Change Declaration

The delivery change is bounded by these paths; a `**` entry includes its descendants:

- `guidelines.md`
- `work-planner/**/*.md`
