**Component:** main:work-planner/modes/deliver-mode.md

## Overview

A Work Planner step that hands work to a sub-agent or runs another mode dispatches it, and a conditional read is deferred.

## Problem

Deliver Mode hands a unit to a sub-agent through prose, Sync Mode runs Understand Mode inline, and Plan Mode compiles Propose and Sync Modes into every bundle.

## Proposal

- Each hand-off and each step running another mode links the procedure followed with `⇉`, or `⫽` for a set.
- Each citation a step reads only in some cases is `¬`, the case stated in the step.
- Prerequisites drop each file reached only through an operator.
- The hand-off and conditional-citation inventories are recorded in the planning record.

### File-Change Declaration

The delivery change is bounded by these paths; a `**` entry includes its descendants:

- `work-planner/**/*.md`
- `work-planner/test/**`
