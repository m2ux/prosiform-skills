**Component:** main:work-planner/modes/sync-mode.md

## Overview

Prose that names another Work Planner mode in passing is plain text.

## Problem

A mode named only to attribute a behaviour is a link, which prosiform compiles whole.

## Proposal

- A mention that sends the reader nowhere loses its link and keeps its words.
- A mode a step runs is left for the dispatch task; Prerequisites drop a mode no step reaches.
- The inventory of links to mode files, each classified as a mention, a run or a prerequisite, is recorded in the planning record.

### File-Change Declaration

The delivery change is bounded by these paths; a `**` entry includes its descendants:

- `work-planner/**/*.md`
- `work-planner/test/**`

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | List every link to a mode file, classified as a mention, a run or a prerequisite. |
| Plan | Settle each mention's wording against the epic's criteria. |
| Implementation | Make the change in the declared component and its declared boundary. |
| Review | Inspect the complete diff against the boundary and trace each caller. |
