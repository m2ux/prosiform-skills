**Component:** main:work-planner/SKILL.md

## Overview

Every Work Planner link names the section its reader needs.

## Problem

A whole-file link compiles the whole target into the bundle where one section was meant.

## Proposal

- Each internal link names the heading its reader needs; a whole-file link stays only for a target with no heading below its title.
- The called operation, and the link text, are preserved.
- The link inventory, each whole-file link and its target's headings, is recorded in the planning record at the task's head.

### File-Change Declaration

The delivery change is bounded by these paths; a `**` entry includes its descendants:

- `work-planner/**/*.md`
- `work-planner/test/**`

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | List every whole-file link outside fenced blocks and code spans, and decide the section each one needs. |
| Plan | Settle each link's section against the epic's criteria. |
