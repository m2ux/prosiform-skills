**Component:** main:work-planner/SKILL.md

## Overview

Work Planner's entry point routes a session to a mode it compiles with prosiform.

## Problem

No mode is an entry, and SKILL.md compiled whole carries every mode.

## Proposal

- SKILL.md is read, not compiled. Its Modes list selects a mode, and its instruction is to run `pf` on the selected mode file and follow that bundle.
- Every document a mode's bundle reads declares `prosiform` in its frontmatter; SKILL.md declares none.
- Conventions and Rules a compiled mode needs reach its bundle by link.

### File-Change Declaration

The delivery change is bounded by these paths; a `**` entry includes its descendants:

- `work-planner/**/*.md`
- `work-planner/test/**`
