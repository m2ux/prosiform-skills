## Overview

Every Work Planner mode compiles within the default output budget with no warning.

## Problem

Five modes exceed the default budget at workflow-server `785a5ee8c`, the content prosiform-skills' `main` starts from.

## Proposal

- Each mode still over the budget is cut to its own procedure, a section only some steps use moved to a file of its own.
- Each mode's compile, run with the pinned `pf` at its default budget, is recorded in the planning record.

### File-Change Declaration

The delivery change is bounded by these paths; a `**` entry includes its descendants:

- `work-planner/**/*.md`
- `work-planner/test/**`
