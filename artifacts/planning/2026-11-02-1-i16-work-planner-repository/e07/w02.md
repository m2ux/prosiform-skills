**Component:** main:work-planner/references

## Overview

Work Planner's content grain is reviewed against bundle size and the distribution of its functionality, and the rubric the review applies is stated for later changes to the skill.

## Problem

Work Planner's design places procedures in modes and protocols, and operations, commands and fields in artifacts. Whether each unit is cut at the size its readers need is unmeasured: a mode's bundle carries content none of its steps use, one capability spreads across several units, and a later change has no standard to be held to.

## Proposal

- Measure each protocol and artifact, and each procedure, operation, command and field section it holds, under the pinned `pf`:
  - **Bundle share**  the bytes it adds to each mode's bundle.
  - **Reach**  how many modes' bundles carry it.
  - **Dead weight**  the share of it compiled into a mode's bundle that none of that mode's steps use.
  - **Cohesion**  whether it does one job, judged against the modes, protocols and artifacts layering, or one job spreads across several units.
- Give each unit a verdict of keep, split, merge or move, with its evidence, in a grain report in the planning record.
- Put each split, merge or move to the user; each confirmed change becomes an E07 row ahead of W02.
- State the measures, thresholds and verdict rules in `work-planner/references/grain-rubric.md`, and have Revise Mode check each new or changed protocol and artifact against it.

### File-Change Declaration

The delivery change is bounded by these paths; a `**` entry includes its descendants:

- `work-planner/references/grain-rubric.md`
- `work-planner/modes/revise-mode.md`

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Compile every mode under the pinned `pf`, attribute each bundle's bytes to the units it carries through their provenance, and read each mode's steps for the units they use. |
| Plan | Settle the thresholds and verdict rules with the user, then each unit's verdict. |
| Implementation | Write the rubric and Revise Mode's check against it; record the report and raise the confirmed rows. |
| Review | Confirm every unit carries all four measures and a verdict, and that each confirmed change has a row. |
| Test | Run `python3 -m unittest discover -s work-planner/test` from the repository root. |
