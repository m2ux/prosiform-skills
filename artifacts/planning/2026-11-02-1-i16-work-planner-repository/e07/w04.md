**Component:** main:scripts/check_skill_files.py

## Overview

The shared check reports a whole-file link to a target with sections, and a mode reached without an operator, in every skill it runs over.

## Problem

The check confirms a link resolves and reads nothing of its scope, so a link compiling a whole file, or a mode compiling another mode, passes.

## Proposal

- A finding for a link with no fragment whose target carries a heading below its title; none for a headingless target or a title heading.
- A finding for a mode or protocol file whose link to a mode file carries no operator.
- The shared guide's Checks entry for the check states these findings.
