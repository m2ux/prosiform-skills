**Component:** main:scripts/check_skill_files.py

## Overview

The shared check compiles each mode of every skill it runs over and reports a bundle over the default budget or a warning.

## Problem

Nothing compiles the skill, so a mode overflowing the budget is found only when a reader's `pf` run fails.

## Proposal

- The check runs `pf` on each mode file with prosiform's default output budget and reads its exit status and diagnostics.
- A failure on the output budget, and each warning, is a finding naming the mode and the figure.
- An absent `pf`, or one reporting another profile than the check names, is a finding; the compile is never skipped.
- The shared guide's Checks entry for the check states its compile run.
