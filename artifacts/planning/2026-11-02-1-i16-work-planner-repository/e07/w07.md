**Component:** main:work-planner/modes

## Overview

Each Work Planner mode compiles against stubs of the artifacts and protocols it links.

## Problem

A mode compiles only with everything it links, so its own prose is never checked apart from theirs, and a fault in one artifact fails every mode that reaches it.

## Proposal

- Each mode's frontmatter declares a `test` preset whose `subst` pairs map each artifact and protocol the mode links to a stub.
- A stub carries the headings the mode's links name and no further links.
- The skill's test suite compiles every mode with `--presets test` and requires exit 0.

### File-Change Declaration

The delivery change is bounded by these paths; a `**` entry includes its descendants:

- `work-planner/modes/**`
- `work-planner/test/**`
