**Component:** main:work-planner/SKILL.md

## Overview

The first history of prosiform-skills' `main`: the work-planner skill and the shared skill files, extracted from workflow-server with their commits and moved up one level, and `main` made the repository's default branch.

## Problem

prosiform-skills has no `main`. Its only branch is the orphan `engineering` branch that holds planning records, which GitHub made the default branch when it was pushed. No epic base can be cut from a branch that does not exist.

## Proposal

The scene is workflow-server's `skills/` folder at the head of `workspace`, which holds the skill beside three unrelated skills and the files every skill there shares.

- **Paths kept.**
  `skills/work-planner/`, `skills/guidelines.md`, `skills/rules.json`, `skills/scripts/check_skill_files.py` and `skills/test/test_check_skill_files.py`. The check script imports nothing beyond the standard library, so nothing further is kept.
- **Extraction.**
  `git filter-repo` runs on a fresh clone of workflow-server at the head of `workspace`, keeping those paths and renaming `skills/` to the root.
- **Publication.**
  The result is pushed directly as `main`, since no base exists for a pull request to target. The row records the pushed head commit as its delivery.
- **Default branch.**
  `main` is set as the repository's default branch once it exists.
- **Check.**
  The tree of `main` is compared with workflow-server's `skills/` at the extracted commit, path for path, and the log of a kept path with its log in workflow-server.
