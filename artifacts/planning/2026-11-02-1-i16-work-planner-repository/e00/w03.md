**Component:** main:scripts/check_skill_files.py

## Overview

The shared skill check and its tests run from the root of prosiform-skills, where the skill they check is `work-planner/` rather than `skills/work-planner/`.

## Problem

The check script and its tests describe a `skills/` folder.

- **Usage.**
  The script's usage text runs `python3 skills/scripts/check_skill_files.py skills/work-planner`.
- **Seeded tree.**
  `test_check_skill_files.py` seeds a `skills/` tree for its whole-run test, the layout the repository no longer has.

## Proposal

The scene is prosiform-skills' root, which holds the skill folder beside the shared guide, rules, script and tests, the shape workflow-server's `skills/` folder had.

- **Usage names the root.**
  The usage text runs `python3 scripts/check_skill_files.py work-planner` from the repository root.
- **Tests seed the root layout.**
  The whole-run test seeds the repository's own shape.
- **Shared files are this repository's own.**
  The guide's examples name paths that exist here.
