**Component:** main:work-planner/scripts/board-queue.py

## Overview

Board Queue ranks epics and initiatives by their board item's Priority number, so the board shows the order the queue runs.

## Problem

Board Queue ranks by `priority: <n>` labels, read by the `RANK` pattern in `board-queue.py`, while the board shows a Priority field nothing reads.

## Proposal

The scene is Board Queue reading one theme board's items, each carrying its issue and its field values.

- **The read.**
  The queue takes each item's Priority from the board's Priority field, fetched with the items.
- **The order.**
  A larger number runs first, and items sharing a number run together.
- **No priority.**
  An empty value is no priority: the epic stays in Backlog and is reported as waiting on a priority.
