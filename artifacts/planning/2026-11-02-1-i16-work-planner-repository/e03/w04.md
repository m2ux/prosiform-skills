**Component:** workspace:vendor/prosiform-skills

## Overview

In m2ux/prosiform, the workspace's submodule pins a prosiform-skills commit whose skill reads the Priority field, so the skill that workspace runs reads the field before the labels go.

## Problem

Until prosiform's pin moves, the skill it runs still reads priority labels, so the labels cannot go.

## Proposal

The scene is prosiform's `workspace` branch and its `vendor/prosiform-skills` submodule.

- **The pin moves.**
  The submodule moves to a prosiform-skills `main` commit whose skill reads the Priority field and names no priority label.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Find the first `main` commit holding the field reading. |
| Plan | Choose the pinned commit. |
| Implementation | Move prosiform's submodule pin. |
